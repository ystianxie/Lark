# 皮肤与主题

在「应用设置 → 外观」选择经典、浅色、深色或磨砂。开启「跟随系统」后，系统明暗变化会自动切换浅色与深色；关闭时保留当前显示的皮肤。点击任意皮肤卡片会退出系统跟随。恢复默认会选择经典。

## 实现入口

- `src/panels/ThemePanel.jsx`：选择卡片、系统跟随、恢复默认与保存反馈。
- `src/theme/ThemeProvider.jsx`：统一驱动 CSS 与 Ant Design，监听系统明暗变化及跨窗口主题事件。
- `src/theme/presets.js`：可选皮肤、偏好归一化与主题解析。
- `src/theme/nativeEffect.js`：顺序更新原生模糊与窗口轮廓；观察搜索区域尺寸及 DPI 变化。截图时暂停并移除裁切，恢复窗口后重新应用。
- `src/theme/tokens.css`：搜索区域和功能面板使用的语义颜色变量。
- `src-tauri/src/config/appearance.rs`：读取、保存外观并广播 `appearance-changed`。

应用配置的 `base.appearance.theme` 保存 `classic`、`light`、`dark`、`frosted` 或 `system`。旧配置缺少该字段时使用经典；未知皮肤名回退到经典。外观独立保存，不经过快捷键注册流程。`localStorage` 中的 `lark.appearance` 仅作为启动缓存，原生配置读取完成后覆盖缓存。原生保存失败时恢复原选择并显示错误。

磨砂皮肤的搜索区域使用乳白半透明表面、蓝灰文字与明确的选中态，功能面板仍使用浅色实底。Windows 启用原生 Blur，通过 `SetWindowRgn` 按搜索区域的边界和圆角裁切，保留无阴影的原生窗口配置，切换皮肤不修改窗口尺寸。轮廓按 WebView 的像素比例换算，随搜索结果、功能面板及屏幕 DPI 变化更新；退出磨砂或进入截图模式时移除模糊及裁切。其他平台或原生调用失败时使用更厚的浅色背景。浏览器预览使用 CSS `backdrop-filter`，不能验证桌面合成器的实际效果。

## 新增页面样式

功能面板使用 `--panel-bg`、`--panel-surface`、`--surface-muted`、`--surface-hover`；文字使用 `--text-primary`、`--text-secondary`、`--text-muted`。强调色使用 `--accent`，强调色上的文字使用 `--text-on-accent`。边框、焦点、滚动条与阴影也使用对应变量。

搜索区域使用独立的 `--launcher-*`、`--result-*` 变量，使经典皮肤可以保留深色搜索与浅色面板的组合。危险、警告、成功状态使用独立的语义颜色。

通知窗口接入相同主题和事件同步。插件可以主动采用这些变量；已有第三方插件中的固定颜色不会自动转换。截图取色界面和代码编辑器保留其专用配色；首次使用向导目前使用自身样式。

## 手动验证

1. 切换四种皮肤，检查搜索输入、结果选中态、各内置面板及表单弹层。
2. 重启应用，确认恢复之前的选择。
3. 开启系统跟随并改变系统明暗，确认实时切换；关闭后确认保持当前皮肤。
4. 显示通知窗口后切换皮肤，确认两个窗口同步。
5. 模拟配置写入失败，确认错误提示和原皮肤恢复。
6. 在 Windows 桌面选择磨砂，确认切换前后窗口尺寸一致、圆角没有黑色缺口；检查紧凑搜索、多条结果、功能面板及不同 DPI 下的轮廓。快速切换其他皮肤，截图时确认全屏区域没有被裁切，退出截图后恢复磨砂。

检查命令：`pnpm build`、`cargo check`、`cargo test config::appearance::tests`。
