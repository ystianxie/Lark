# 首次启动自动建立应用与文件索引

日期：2026-09-21
当前步骤：Complete

## 目标

在配置中保存应用索引与文件索引是否成功完成过全量扫描，并在应用启动时按“应用优先、文件随后”的顺序后台补建尚未初始化的索引。

## 已确认行为

- 新安装的两个初始化标志默认为 `false`。
- 旧配置缺少标志时：对应索引有数据则补写 `true`，为空则补写 `false` 并触发扫描。
- 文件扫描路径为 `Some([])` 时尊重用户选择，不恢复默认路径、不扫描，并将文件索引视为已处理。
- 每项扫描只有成功后才写入 `true`；失败保持 `false`，下次启动重试。
- 应用扫描失败不阻止文件扫描。
- 首次扫描运行在后台，不阻塞窗口、快捷键和托盘初始化。

## 验证

- 配置迁移测试：缺少字段时可识别为旧配置，并按索引数据补值。
- 空路径测试：`Some([])` 不触发文件扫描。
- 扫描结果测试：只有成功时持久化完成标志。
- Rust 格式检查、目标测试、diff 检查与可用的编译检查。

- 不并发执行首次应用扫描与文件扫描。
- 不修改前端设置页面。
