# 启动时周期校准文件索引

日期：2026-09-29
当前步骤：Review complete

## 目标

记录最近一次成功完成的文件索引全量重建时间；应用启动后，当该时间缺失、索引状态为 `Stale`，或距离上次成功重建已超过 10 小时时，在后台复用现有原子重建链路校准索引。

## 已确认行为

- 首次索引仍按现有启动流程立即补建。
- 已初始化索引在启动约 15 秒后判断是否过期，避免与启动初始化争抢资源。
- 只有全量扫描提交成功、重建期间积累的增量变更完成补写后，才保存成功时间。
- 扫描失败、增量补写失败或任务已经运行时，不更新时间。
- 搜索在扫描阶段继续读取现有正式索引；不新增扫描实现。
