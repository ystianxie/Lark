## 七、第一阶段范围声明

- 第一阶段仅验收 Windows 本地目录；不承诺 macOS、Linux 或网络盘的监听行为。
- `notify` 保留跨平台依赖能力，但路径大小写、分隔符、FSEvents 行为和 macOS 隐私权限适配留到后续阶段。
- 没有可用的 macOS 实机或 CI 前，不将 macOS 标记为已支持平台。

## 八、当前明确不支持的范围

以下场景当前不纳入实施和验收范围，后续如需支持需要单独评估：

- [ ] macOS/Linux 的 watcher 行为验收（暂不实施）
- [ ] 网络盘监听（暂不支持）
- [ ] 移动磁盘插拔和恢复（暂不支持）
- [ ] 复杂权限目录、系统保护目录的监听（暂不支持）

这些项目不是当前版本的遗漏；产品行为应允许监听失败或跳过不可访问目录，并保留手动重建索引作为恢复方式。
