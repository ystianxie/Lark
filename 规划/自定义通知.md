# 你的目标架构

```rust
pub struct Notification {
```

Action：

```rust
pub enum NotificationAction {
```

# Action 我建议不要做成“通知自己的逻辑”

你这个想法其实是对的：

> 打开、打开目录、关闭等是 Notification 常见 Action，封装成函数。

但我建议进一步做成：

**Action 是数据，执行由 Rust 完成。**

比如前端：

```typescript
notify.success({
  title: "下载完成",
  message: "xxx.zip",
  actions: [
    {
      type: "open",
      path: "/Downloads/xxx.zip"
    },
    {
      type: "open_dir",
      path: "/Downloads"
    }
  ]
});
```

Rust：

```rust
pub enum NotificationAction {
    Open(PathBuf),
    OpenDir(PathBuf),
    Close,
}
```

点击：

```text
用户点击“打开”
       ↓
通知窗口
       ↓
Tauri invoke
       ↓
Rust
       ↓
NotificationAction::Open
       ↓
Windows Shell
       ↓
打开文件
```

这样安全性和可控性都会更好。

# 至于你说的“暂停通知 / 不通知”

这个我非常赞同：

**不要放到 Notification 本身。**

例如不要搞：

```typescript
notify({
  title: "...",
  silent: true,
  paused: true,
  disable: true,
  ...
});
```

这样 Notification API 很快就会变得很乱。

应该是另外一个：

```typescript
notificationManager.pause()
notificationManager.resume()
```

或者：

```typescript
notificationManager.setEnabled(false)
```

甚至：

```typescript
notificationManager.setMode("silent")
```

架构上：

```text
Notification
    │
    ├── title
    ├── message
    ├── level
    └── actions


NotificationManager
    │
    ├── enabled
    ├── paused
    ├── queue
    ├── max_visible
    └── position
```

这就非常干净。

```text
        │
```

### 一个通知窗口 = 一个 WebView

窗口内部：

```text
NotificationContainer

 │ Notification #2  │
 ├──────────────────┤
```

这样有几个好处：

* 多通知堆叠容易
* 动画容易
* 窗口数量少
* Rust 管理简单
* 前端 CSS 管理 UI
* 性能更好

# Rust 和前端通信

可以定义：

```rust
#[tauri::command]
fn notify(
    app: AppHandle,
    notification: Notification,
) -> Result<(), String> {
    // ...
}
```

前端：

```typescript
await invoke("notify", {
  notification: {
    level: "success",
    title: "下载完成",
    message: "xxx.zip",
    actions: [
      {
        type: "open",
        path: "/Downloads/xxx.zip"
      }
    ]
  }
});
```

然后你再包一层：

```typescript
export const notify = {
  success(options) {
    return invoke("notify", {
      notification: {
        level: "success",
        ...options,
      },
    });
  },

  error(options) {
    return invoke("notify", {
      notification: {
        level: "error",
        ...options,
      },
    });
  },

  info(options) {
    return invoke("notify", {
      notification: {
        level: "info",
        ...options,
      },
    });
  },
};
```

最终业务代码就会非常漂亮：

```typescript
notify.success({
  title: "下载完成",
  message: "xxx.zip",
  actions: [
    actions.open(file),
    actions.openDir(file),
  ],
});
```
