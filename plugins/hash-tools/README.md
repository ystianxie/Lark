# Hash / 加密工具

浏览器本地执行的摘要、消息认证和文本加密工具。输入不会上传到网络。

## 功能

- SHA-1 / SHA-256 / SHA-384 / SHA-512 摘要
- Hex / Base64 输出
- 摘要结果校验（Hex 不区分大小写，Base64 严格区分大小写）
- HMAC 生成与验证
- AES-256-GCM 文本加密与解密
- 加密使用 PBKDF2-SHA256（600,000 次迭代）、随机 salt 和随机 IV
- 支持空文本；HMAC 密钥和 AES 密码不能为空
- 单次文本输入上限 8 MiB，加密数据包上限 12 MiB

AES 解密只接受本工具生成的完整 JSON 数据包，不会猜测其他工具的密文格式。请把数据包和密码分开保存；密码丢失后无法恢复明文。
